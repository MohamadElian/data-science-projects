# Sales Forecasting Model

## Overview
This project focuses on forecasting monthly sales trends using regression models and time-based feature engineering. The goal is to simulate real-world business forecasting scenarios and support data-driven decision making.

## Methods
- Linear Regression for time-series forecasting
- Time-based feature engineering (Month index)
- Seasonal modeling (month-by-month regression)
- Scenario-based forecasting with growth adjustments (+15%)

## Process
1. Cleaned and formatted time-series sales data
2. Created numerical time features to represent trends
3. Trained regression models to predict future sales
4. Generated forecasts for:
   - April–December 2025
   - Full-year 2026 using seasonal modeling
5. Applied growth scenarios to simulate business changes

## Results
- Produced structured forecasts for multiple product categories
- Captured seasonal patterns in sales behavior
- Simulated growth scenarios to reflect real-world business conditions

## Tools Used
- Python
- pandas
- NumPy
- scikit-learn
