# Data Source

This project uses data from the Genomics of Drug Sensitivity in Cancer (GDSC) dataset.

## Sources

- Kaggle Version:
https://www.kaggle.com/datasets/samiraalipour/genomics-of-drug-sensitivity-in-cancer-gdsc?select=GDSC2-dataset.csv

- Original Source:
https://www.cancerrxgene.org/

## Description

The GDSC dataset contains information on cancer cell lines and their responses to various drugs. It is widely used in bioinformatics to study drug sensitivity and support research in precision medicine.

## Notes

Due to the large size of the dataset, only a sample or processed version may be included in this repository. Users can access the full dataset through the links above.
