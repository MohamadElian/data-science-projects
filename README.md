# Data Science Projects Portfolio

This repository contains projects focused on machine learning, bioinformatics, and business forecasting. Each project demonstrates the use of data analysis, predictive modeling, and real-world problem solving.

## Projects

### Drug Response Prediction (GDSC)
- Built machine learning models to predict drug sensitivity (LN_IC50) using genomic data
- Models: Ridge Regression, HistGradientBoosting
- Dataset: GDSC (Genomics of Drug Sensitivity in Cancer)
- Performance: R² ≈ 0.74, RMSE ≈ 1.4

### Sales Forecasting Model
- Developed regression-based forecasting models for monthly sales trends
- Applied time-based feature engineering and seasonal modeling
- Generated forecasts for 2025 and 2026 with growth scenarios

## Tools & Technologies
- Python
- pandas, NumPy, scikit-learn
- Data analysis and visualization

## Purpose
These projects demonstrate practical applications of data science in both healthcare (bioinformatics) and business analytics.
